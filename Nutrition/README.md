# Nutrition

Everything food-related lives under this folder.

## Structure

| Folder | What’s in it |
|--------|----------------|
| **Recipes/** | Cook instructions (one note per recipe) |
| **Meal Plans/** | Weekly schedules that link to recipes |
| **Library/** | Macros plugin food database (per-serving macros) |
| **Daily/** | Daily intake logs (`YYYY-MM-DD` notes + template) |
| **Shopping/** | Shopping lists |

## Macros plugin

In Obsidian → Macros plugin **Settings → Storage folder** = `Nutrition/Library`.

Daily logs go in `Nutrition/Daily` (do not use a folder named Macros).

See [[Library/README|Library README]] for targets and logging examples.
