# Nutrition (Macros plugin)

Marcus logs foods/recipes here for the Obsidian **Macros** plugin.

## How it works
1. Food files in this folder have frontmatter (`calories`, `protein`, `fat`, `carbs`, `serving_size`).
2. Daily log: put a `macros` code block in a note (date id `YYYY-MM-DD`) and add foods/meals by name.
3. Recipe meals below are **per-serving estimates** (marked `source: marcus_estimate`) — good enough for deficit coaching; refine with live search when you want exact packaged items.

## Daily log example
````markdown
```macros
id: 2026-09-06

meal: Breakfast @07:00
- Wake-up Wrap: 1
- Protein Smoothie: 1

meal: Lunch @12:30
- Instant Pot Chili (serving): 1

meal: Dinner @18:30
- Butter Chicken Bowl (serving): 1
```
````
