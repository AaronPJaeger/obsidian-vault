# Daily macros log

Copy into today’s note (or a Macros daily note). Change the `id` to today’s date.

````markdown
```macros
id: YYYY-MM-DD

meal: Breakfast
- Wake-up Wrap: 1
- Protein Smoothie: 1

meal: Lunch
- Instant Pot Chili (serving): 1

meal: Dinner
- Butter Chicken Bowl (serving): 1

meal: Snacks
- Cottage cheese // if used
```
````

Optional chart:
````markdown
```macrospc
id: YYYY-MM-DD
```
````
