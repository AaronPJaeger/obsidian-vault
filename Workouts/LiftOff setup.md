# LiftOff setup (Marcus)

1. Install **LiftOff** from Obsidian Community Plugins (phone + desktop).
2. Settings:
   - **Workout folder:** `Workouts`
   - **Template folder:** `Workouts/Templates`
   - **Weight unit:** lbs
3. Start Monday from template **Day A Push**, Wed **Day B Pull**, Fri **Day C Legs**.
4. After you save a session, ping Marcus — he’ll update `Workouts/Log.md` coaching notes.

Templates use LiftOff frontmatter (`type: workout-template`). Don’t rename the `type` field.
