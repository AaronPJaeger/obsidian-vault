# Wardrobe

Aaron’s clothes inventory — basic / cheap / no designer. Use this to build outfits and spot gaps before buying.

**Out of scope:** Houndstown uniforms (jeans + HS tee).

**Focus:** IT / everyday, weekends, church.

## How to update
- Add what you have (count + color + condition if useful)
- Mark gaps in `Gaps.md`
- Outfit ideas live in `Outfits.md`
